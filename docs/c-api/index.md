# C API

WIPI-C 응용프로그래밍 인터페이스. 응용프로그램이 플랫폼 위에서 사용할 수 있는
C 언어 API 들을 정의합니다. 함수는 `MC_` 접두사를 갖습니다 (예: `MC_knlCalloc`,
`MC_grpDrawLine`).
