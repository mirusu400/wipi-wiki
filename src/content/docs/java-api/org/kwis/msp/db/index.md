## Interface Summary

- [DataComparator](datacomparator/) — 두개의 레코드를 비교하는 인터페이스입니다.
- [DataFilter](datafilter/) — 정렬에 사용할 레코드를 제한합니다.

## Class Summary

- [DataBase](database/) — 영속적인 데이터를 저장하고, 찾으며, 관리하기 위한 메카니즘을 제공합니다.
- [DataComparatorInteger](datacomparatorinteger/) — 두개의 레코드를 정수로 비교하는 클래스입니다.
- [DataComparatorString](datacomparatorstring/) — 두개의 레코드를 문자열로 비교하는 클래스입니다.
- [DataFilterInteger](datafilterinteger/) — 정렬에 사용할 레코드를 한정합니다.

## Exception Summary

- [DataBaseException](databaseexception/) — 데이터베이스와 관련된 일반적인 예외 상황에서 발생합니다.
- [DataBaseRecordException](databaserecordexception/) — 데이터베이스의 레코드와 관련된 일반적인 예외 상황에서 발생합니다.
