---
title: "3. 기본 ERROR 반환 값"
---

에러 코드 값 설명 비고 `M_E_ERROR` -1 기타 에러 `M_E_BADFD` -2 잘못된 식별자 `M_E_BADFILENAME` -3 잘못된 파일 이름 `M_E_BADSEEKPOS` -4 잘못된 파일 위치 `M_E_EXIST` -5 해당 리소스가 이미 존재함 `M_E_BADFORMAT` -6 잘못된 포맷 `M_E_INPROGRESS` -7 오퍼레이션 수행 중 `M_E_INUSE` -8 현재 사용 중이거나 이미 사용 중 `M_E_INVALID` -9 매개변수가 잘못되었음 `M_E_ISCONN` -10 이미 연결이 설정되어 있음 `M_E_LONGNAME` -11 제한길이 초과 `M_E_NOENT` -12 내용 없음 `M_E_NOSPACE` -13 남은 공간이 없음 `M_E_NOTCONN` -14 연결이 설정되어 있지 않음 `M_E_NOTEMPTY` -15 비어있지 않음 `M_E_NOTSUP` -16 해당 서비스를 지원하지 않음 `M_E_NOMEMORY` -17 메모리 부족 `M_E_SHORTBUF` -18 버퍼가 작음 `M_E_WOULDBLOCK` -19 would block 발생 `M_E_TIMEOUT` -20 타임아웃 `M_E_DATABIG` -21 데이터가 너무 큼 `M_E_BADRECID` -22 잘못된 레코드 식별자 `M_E_EOF` -23 파일의 끝 `M_E_ACCESS` -24 접근에러 `M_E_NORESOURCE` -25 리소스 부족 `M_E_NOEXIST` -26 해당 파일/리소스 존재하지 않음 `M_E_BADVERSION` -27 애플리케이션 수행을 지원하지 못하는 플랫폼 버전
