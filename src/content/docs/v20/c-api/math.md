### MC_mathCheck

**프로토타입**

```c
M_Boolean MC_mathCheck(M_Int32 a, M_Int32 b, M_Int32 c)
```

**설명**

지정된 정수 값이 지정된 범위내에 있는지를 검사하여 그 결과를 리턴한다.

**매개 변수**

- `a` - 검사 시작 값
- `b` - 검사 끝 값
- `c` - 범위 내에 존재하는지 검사하고자 하는 값

**반환 값**

성공

- `TRUE(두` - 값 사이에 있는 경우)
실패

- `FALSE(두` - 값 밖에 있는 경우)
