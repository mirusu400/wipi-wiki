본 규격에서 정의하는 모바일 표준 플랫폼은 개념적으로 [그림 2-1]과 같은 구조를 갖 는다. 단말기 기본 S/W는 통신 기본 기능과 각종 디바이스 드라이버가 포함된다. 응용 프로그램 필수 API(MSF/MSP/WIPI-C /CLDC/MIDP 모바일 표준 플랫폼 HAL 단말기 기본 소프트웨어 Handset Hardware [그림 2-1] 개념적 구조도

## 2.1. HAL

플랫폼 이식에 있어서 하드웨어 독립성을 지원하기 위한 계층이다. 이를 통해 단말 기에 대한 추상화가 이루어지고, 하드웨어 독립적으로 플랫폼이 구성된다.

## 2.2. 필수 API

응용프로그램 개발자가 사용하는 플랫폼에서 지원하는 필수 API 모음이다. C 및 Java API를 제공한다.
