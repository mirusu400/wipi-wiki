## Class Summary

- [GameCanvas](GameCanvas) — GameCanvas 클래스는 게임 사용자 인터페이스 기반을 제공합니다.
- [Layer](Layer) — Layer는 게임의 시각적 요소를 나타내는 추상 클래스입니다.
- [LayerManager](LayerManager) — LayerManager는 일련의 Layer를 관리합니다.
- [Sprite](Sprite) — Sprite는 Image에 저장되어 있는 여러 프레임 중 하나를 사용하여 렌더링할 수 있는 기본 시각적 요소입니다.
- [TiledLayer](TiledLayer) — TiledLayer는 타일 이미지 집합으로 채울 수 있는 셀의 격자로 구성된 시각적 요소입니다.
