title: "4.1. 한국어(EUC_KR) 지원을 위한 확장 유니코드"

기본적으로 KSC5601에서 (0xA1A0-0xACFF)의 영역을 (0xE1A0-ECFF)의 영역으로 매핑시킨다. 변경하는 함수는 다음과 같다. Unicode Character Value = KSC5601 Character Value | 0xE000 SC5601 Character Value = Unicode Character Value & 0xAFFF 하는 코드 character는 <표 4-1-1>과 같다. (표에 나타나 있는 Code값은 KSC5601값 이다.)
